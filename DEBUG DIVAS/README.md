\# Cognitive Radio Spectrum Monitoring System



This project demonstrates detection and prevention of unauthorized spectrum usage using:



\- Signal generation

\- FFT-based energy detection

\- Machine learning (Logistic Regression)

\- Interactive Streamlit interface



\## Project Structure



01\_signal\_generation  

02\_spectrum\_sensing  

03\_unauthorized\_detection  

04\_frontend\_demo  



\## How to Run Frontend



```bash

pip install -r requirements.txt
